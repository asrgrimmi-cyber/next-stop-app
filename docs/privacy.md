# Privacy

- **Self-hosted:** all data stays on your server in `data/`. Nothing is sent anywhere else.
- MCP tokens and sessions are stored as SHA-256 hashes. Revoke tokens in Settings.
- **When you connect Claude,** Claude reads and writes your flights through the tools you allow. Anthropic's usual terms apply to that conversation.
- **The GitHub Pages edition** stores tasks only in your browser (localStorage). Its optional tester check-in is configured by whoever deploys it (`pages/tester-log.gs`) and never sends task names.
