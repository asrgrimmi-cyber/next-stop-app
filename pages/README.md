# Next Stop — test build

Your to-do list as an airport departures board. Every task is a **flight**, every step is a **ticket** you tear, and finishing everything prints a **boarding pass**.

**Live:** https://asrgrimmi-cyber.github.io/next-stop/

> This is a **test build**. Everything you enter stays **in your own browser**: there's no account and nothing is uploaded. Please break it and tell us how (see [TESTING.md](TESTING.md)).

## First 60 seconds
1. Open the link. A short guide points out where everything is. Each step has **Skip**.
2. Tap **Book a flight**. Only **“Where to?”** is required. Everything marked *Optional* can be left empty.
3. Tap your flight on the board, then **pull each ticket stub to the right** (or press and hold it) to tear it.
4. When every ticket is torn, your boarding pass prints. Tear it to **depart**.

## Where things are
| Area | What it does | Do I need it? |
|---|---|---|
| **Book a flight** (red button) | Add a task | ✅ Start here |
| Line colours (G W L H P) | Gym / Work / Learn / Home / Personal filter | Optional |
| Departures board | Your flights sorted by time, with status | Read-only, tap a row |
| Flight page | Tickets to tear, platform timer, boarding pass | Opens when you tap a row |
| Stats strip | Torn today, streak, miles | Automatic |
| ⚙ Settings | Name, sounds, lettering, **backup / restore**, replay guide, erase | Optional |
| **Report a problem** (bottom-left) | Opens a GitHub issue with your device info filled in | When something breaks |

## Known limits of this build
- Data lives in **this browser only**. A different browser or device starts empty, and clearing site data erases it. Use *Settings → Download backup*.
- No login, no sync and no Claude connection. Those need the Next Stop server, which isn't part of this build.
- “Last call” notifications only work while the tab is open (and on iPhone only after *Add to Home Screen*).

## Project layout

```
sw.js               service worker for last-call notification clicks

TESTING.md          the stress-test guide for testers
.github/ISSUE_TEMPLATE/bug_report.md
```
This folder is generated by `pages/build_pages.py` in the main Next Stop project. Edit the source there, rebuild, and push.
