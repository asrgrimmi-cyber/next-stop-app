# Claude Project for Next Stop

This folder sets up a **Claude Project** that manages your Next Stop board.

1. Connect the MCP server first → [../docs/connectors.md](../docs/connectors.md)
2. In claude.ai or Claude Desktop, go to **Projects → Create project** and fill it in from [project-settings.md](project-settings.md).
3. Paste [project-instructions.md](project-instructions.md) (everything below its line) into **Project instructions**.
4. Start chats inside the project. Try the prompts in [starter-prompts.md](starter-prompts.md).

For Claude Code, copy `project-instructions.md` into the `CLAUDE.md` of the folder you work from.
